# PatternsOOP

Десять классических паттернов проектирования на C# — каждый в виде самостоятельного демо, которое
запускается из консольного меню. Учебная работа по курсу ООП.

## Зачем

Паттерны проще понять, когда видишь не диаграмму, а работающий код: вот проблема, вот объекты,
вот что печатается на каждом шаге. Каждый паттерн здесь реализован на своём маленьком примере —
сборка компьютера, оплата заказа, домашний кинотеатр и т. п.

## Что внутри

| Паттерн | Где смотреть | Пример |
|---------|--------------|--------|
| Singleton | `Patterns/ConfigurationSingleton.cs` | конфигурация приложения |
| Factory | `Patterns/TransportFactory.cs` | создание транспорта |
| Builder | `Patterns/ComputerBuilder.cs` | сборка компьютера |
| Adapter | `Patterns/PaymentAdapter.cs` | оплата через «чужой» интерфейс |
| Decorator | `Patterns/EmailDecorator.cs` | дополнительные уведомления |
| Facade | `Patterns/HomeTheaterFacade.cs` | включение кинотеатра одной командой |
| Observer | `Patterns/IObserver.cs` | подписчики на события |
| Strategy | `Patterns/IPaymentStrategy.cs` | разные способы оплаты |
| Command | `Patterns/ICommand.cs` | команды с отменой |
| State | `Patterns/ITvState.cs` | состояния телевизора |

Класс паттерна лежит в `Patterns/`, сценарий запуска — в `PatternsDemo/` (реализует `IPatternDemo`
с именем и методом `RunDemo`). `PatternManager` хранит демо по имени, `Program` печатает список
и запускает выбранное.

## Запуск

```
dotnet run --project PatternsOOP
```

В консоли появится список паттернов; введите имя точно как в списке — например `Singleton` —
и нажмите Enter.

## Требования

.NET 8 SDK, внешних зависимостей нет.

## Ограничения

* Меню одноразовое: один паттерн за запуск, без повторов.
* Имя ищется по точному совпадению, регистр важен (`singleton` не найдётся).
* Тестов нет — демо проверяются глазами по выводу в консоль.
